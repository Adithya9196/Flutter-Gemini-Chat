
# Flutter Gemini Chat App

A modern **AI chat application built with Flutter**, powered by **Google Gemini API**, featuring **persistent local chat storage using Hive**, clean UI, and secure API key handling.

---

## Features

* Real-time AI chat using **Google Gemini**
* **Continuous conversation** using previous chat context
* **Local chat persistence** with Hive
* Light & Dark theme support
* Edit and resend messages
* Copy messages easily
* Clear entire chat history

---

## Tech Stack

* **Flutter** (Material 3)
* **Dart**
* **Google Generative AI (Gemini)**
* **Hive** 
* **Provider** 
* **flutter_markdown** (Markdown rendering)
